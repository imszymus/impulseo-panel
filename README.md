# Impulseo — panel sterowania

Panel sprzedazowy: kalendarz z przypomnieniami, kasa, insighty o domykaniu, materialy do nauki.

- **Kod** (to repo) jest publiczny.
- **Dane** (klienci, kwoty, kalendarz) siedza w prywatnym repo `impulseo-dane` i nigdy tu nie trafiaja.

Panel bez tokenu dziala tylko lokalnie w przegladarce. Token wklejasz raz na kazdym urzadzeniu
przyciskiem w prawym gornym rogu.
